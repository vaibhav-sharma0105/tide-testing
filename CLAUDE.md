# TIDE Foundation Website — Claude Context

## Fundamental Rule — Facts Only
**Never assume, fabricate or forge data.** Every claim, number, name, URL, quote, status or result must come from a source of truth: the code, a file, a command's real output, an official document, the live site, or the owner. Then:
- **State the source** (file:line, command, URL, or "the owner said") for anything that matters.
- **If something isn't verified, say so plainly** ("not verified", "I couldn't check this") — don't present a guess as fact, and don't fill gaps with plausible-sounding content.
- **If the information isn't available, ask** instead of inventing it — this includes content for the site (names, designations, figures, links, copy).
- **Report outcomes as they really are**: failed tests, skipped steps, partial results and errors are stated, not smoothed over.

## Project Overview
React static site rebuild of [tideinternational.org](https://tideinternational.org/) for TIDE Foundation (Together in Development and Education), an NGO in Ahmedabad, India focused on educational reform. `AGENTS.md` is the detailed reference (component/hook/utility APIs, full repo tree, §11 Gotchas, §12 tests).

## Tech Stack
- **Vite 8 + React 19** static site; **React Router v7** `BrowserRouter` (clean URLs, not hash routing). **Every public page is prerendered at build time** (`scripts/prerender.mjs`, audit P3 2026-11-24): `npm run build` = `vite build` + headless Chromium (Playwright, dev dep) saving each route as real HTML (`dist/about/why-tide.html`, one file per Resource Centre row, `404.html` = the NotFound page, forwarding pages for the redirect routes, `llms-full.txt`); the app does not hydrate it — `src/main.jsx` preloads the page's code and renders it fresh over the HTML. Route list for the build: `src/config/siteRoutes.js` (a test keeps it equal to `src/routes.js`)
- **Tailwind CSS v3**, **Framer Motion 12**, **Lucide React**, **react-helmet-async** (always via `src/components/ui/SeoHead.jsx`)
- **English only.** The multilingual framework (i18next, `t()`, language switcher) was removed; it is preserved in the local git tag `archive/multilingual-framework` (`git show archive/multilingual-framework:<path>`).

## Deployment & CI
- `npm run build` → `dist/` → GitHub Pages at `/tide-testing/`. `vite.config.js` sets base `/tide-testing/` when `GITHUB_ACTIONS` is set, else `/` — so dev hides base-path bugs (see `imgSrc` below). The build needs no secrets.
- `.github/workflows/deploy.yml` (push to `main` / manual): `npm ci` → `npm run lint` → `npm run content:validate` → `npm test` → `npm run build` (incl. prerender) → `npm run check:dist` (links, sitemap, bundle budget) → `npm run test:e2e:site` (Playwright, Chromium, against the built base-path `dist/` served Pages-style by `scripts/serve-pages.mjs`; `e2e/site/` + `e2e/a11y.spec.js`) → deploy. Any failure stops the deploy (also a deploy started by a sync). Not in CI: the dev-server specs (`npm run test:e2e`) and the visual baselines (`test:e2e:visual`, Windows-only) — run them locally; `e2e-nightly.yml` (02:41 UTC) runs `test:e2e:full` (3 browsers, full responsive matrix). Details: AGENTS.md §12.
- `.github/workflows/sync-pramaan-library.yml` syncs the Resource Centre, `.github/workflows/sync-publications.yml` the Publications pages and `.github/workflows/sync-partners.yml` the Partners page and `.github/workflows/sync-social-changemakers.yml` the Past SCF profiles (all below); each starts `deploy.yml` itself after committing. All six workflows (deploy, nightly e2e, four syncs) open/close `automation-alert` Issues assigned to repo variable `ALERT_ASSIGNEE`; all pin `ubuntu-24.04` and Node 24 (bump deliberately), and every action to a commit SHA (`.github/dependabot.yml` proposes action and npm updates monthly, npm with a 7-day cooldown); checkouts use `persist-credentials: false` and the syncs give `GH_TOKEN` only to the steps that call GitHub (`workflowSecurity.test.js`). `deploy.yml` grants `pages`/`id-token` write to its deploy job only. Mechanics: AGENTS.md §10.

## Design System
- Primary `#1E6BAA` · Background `#FDFCF9` · Text `#0D1F3C` · Accent `#F59E0B` — full token map in `tailwind.config.js` (trust it over any doc).
- **Accent as text/icon only on dark backdrops** (5.9–7.6:1). On light backgrounds use `text-accent-deeper` (`#843A0C`, 7.9:1); `#F59E0B` there is ~2.1:1 and fails WCAG AA. Text is held to **AAA 7:1** (owner decision 2026-11-25): `tide-muted` / `tide-mutedOnLight` `#44515F`; brand blue as body-size text and blue fills behind white text use `primary-dark` (`#15538A`, never plain `text-primary`); plain `primary` stays for fills, borders and large shapes. See AGENTS.md §3.
- Fonts: `font-display` (Playfair Display) and `font-body` (Plus Jakarta Sans), each with Noto Devanagari/Gujarati glyph fallbacks — Gujarati is needed for Pramaan resource titles; keeping Devanagari is an owner decision.
- **Motion (rules 2026-11-24):** one system in `src/utils/motionPresets.js` (`fadeUp`, `revealDelay`, `REVEAL`, `EASE_OUT`): 10px rise, 0.45s, a curve that starts fast, starts as content reaches the window, a row done within 0.2s. Nothing on the first screen waits (banners static; page changes fade in over 0.2s, the first page of a visit has no fade). At most **one count-up per page** (`CountUpText`, the page's main figure: homepage lives, Partners total, Pramaan resources); never years, small numbers or numbers inside a sentence. Details: AGENTS.md §3 "Scroll animation pattern".
- **Accessibility:** audited against WCAG 2.2 AA (2026-06-22) and again towards AAA (audit P2, 2026-11-24: `docs/audits/2026-11-site-audit.md`); lint doesn't check it, `e2e/a11y.spec.js` does (axe AA = 0 on every route and open dialog/menu, keyboard flows; dev server locally and the built site in CI). Decorative loops stop within 5 s (`useLoopWindow`, WCAG 2.2.2); after a page change focus moves to the new `<h1>` (`Layout`); `scroll-padding-top` in `src/index.css` keeps focus clear of the fixed header and sticky sub-bars (`data-sticky-subnav`); Gujarati runs in Sheet text get `lang="gu"` (`LangText`, `utils/scriptLang.js`). Re-scan: `npx vite --port 5175`, then `node scripts/a11y-audit.cjs` (AGENTS.md §12). The global `:focus-visible` ring (`src/index.css`) is a brand-blue outline plus a white band so it shows on navy sections — check git history around that date before changing interactive components or colour tokens.

## CMS Pipeline
```
content/pages/*.yaml + content/shared/*.yaml  →  scripts/yaml-to-json.js (predev/prebuild)  →  src/data/*.json  →  React imports
content/shared/site.yaml + llms.txt           →  scripts/siteDataPlugin.js (Vite)  →  index.html JSON-LD/<title>/og:site_name, /llms.txt, /robots.txt, /sitemap.xml
```
- **Never edit `src/data/`** — it is regenerated (flat: one JSON per YAML basename, so never reuse a basename across `pages/` and `shared/`; stale JSON is never deleted). The Sheet files there (`sheets/pramaan-library.json`, `pramaan-library-photos.json`, `sheets/publications.json`, `publications-photos.json`, `sheets/partners.json`, `partners-photos.json`, `sheets/social-changemakers.json`, `social-changemakers-photos.json`) are written by the sync bots — never hand-edit those either.
- Commands: `npm run content:sync` · `content:validate` (YAML syntax, every local image path whatever its key, Resource Centre, Publications, Partners and Social Changemakers snapshots, `formUrl`, email/lives-impacted consistency) · `dev` (localhost:5173) · `build` · `lint` · `test` (Vitest, 46 files / 524 tests) · `test:e2e` (dev server) · `test:e2e:site` / `test:e2e:full` / `test:e2e:visual` (built site) · `check:dist`.
- **No hardcoded visible text:** every visible string comes from YAML (`data.*`, `common.*`, `ui.*`), never typed into JSX. `react/jsx-no-literals` is an **error** in `src/pages/**` and `src/components/**`; a `no-restricted-syntax` guard beside it (2026-11-24) also fails on words in text props (`alt`, `aria-label`, `title`, `placeholder`, `label`, `badge`, …) and on `{'…'}` / template-literal text in JSX (`src/test/scripts/cmsGuard.test.js`). It can't see text built in plain JS outside JSX — follow the convention anyway (`cms-integrity` skill). Variable text uses `{token}` placeholders filled in code.
- **Site-wide facts** (name, url, email, `livesImpacted`, `gradeRange`, `placeholderImage`, `breadcrumbs.*`, …) live only in `content/shared/site.yaml`. A page's last breadcrumb is `meta.breadcrumbName` in its own YAML.
- Icons and Tailwind classes can't live in JSON: store a key in YAML (`iconKey`, `colorKey`) and map it in the component; never build Tailwind class names dynamically.
- Guides: `CONTENT-GUIDE.md` (non-technical), `.claude/skills/content-management.md` (agent reference).

## Known Gotchas and Open Decisions
- **`imgSrc()` is not idempotent** under `/tide-testing/`: applying it twice breaks the URL on GitHub Pages (invisible in dev). `Lightbox` applies it itself — pass raw YAML paths. Verify with a `GITHUB_ACTIONS=true` build + preview — `vite preview` needs `GITHUB_ACTIONS=true` set too (else every `/tide-testing/*` page is blank) and answers 200 for any path; `scripts/serve-pages.mjs` shows real 404s and folder redirects. In Git Bash set `MSYS_NO_PATHCONV=1`, or a `/tide-testing/` argument becomes a Windows path.
- **Sheet text is untrusted (audit P4):** a Sheet URL used as `href`/iframe `src` goes through `safeHttpUrl` / `safeEmbedUrl` (`src/utils/safeUrl.js`); JSON-LD is written with `jsonLdText` (`src/utils/jsonLd.js`), never plain `JSON.stringify`, because the prerender saves it as HTML; sync image decoding starts with `assertSafeImage` (`scripts/lib/image-safety.js`). The built CSP allows only hashed inline scripts (dev keeps `'unsafe-inline'`), so a new runtime-injected script works in dev but fails the prerender. AGENTS.md §10.
- **Prerendered pages:** the app does not hydrate; each page sits in its own `ErrorBoundary inline` inside `Layout` (header/footer survive a page crash), and the build fails on a page with ≠ 1 `<h1>`, no title, a wrong canonical or a console error.
- **Don't write a literal `<title>` inside an HTML comment in `index.html`** — `siteDataPlugin`'s regex would replace it instead of the real one; keep the `<!-- site-jsonld -->` marker.
- **Owner-decided facts:** email `tidefoundation@gmail.com`, lives impacted `52,500+`, everywhere; `content:validate` errors on any other value in `content/`.
- **Failed images** are swapped site-wide for `site.placeholderImage` (`src/utils/imagePlaceholder.js`), which hides typos — check filenames. Opt out with `data-no-placeholder` (`DriveImage` does). `content:validate` warns on any YAML value that is a local file path (`/assets/…`, `assets/…` or an image extension) whose file is missing or that has no folder (since 2026-11-24, audit P1).
- **Deleted files are recoverable:** removed pages/images/components from 2026-10-25 via `git checkout a4126d1 -- <path>` (list in AGENTS.md §11).
- **Open (not decided):** `site.yaml` `gradeRange` ("1–5") must agree with `LIBRARY_GRADES` in `src/utils/libraryFilters.js` (a unit test checks it); Foundational has no resources yet.
